# ⚡ Live-лента

Сайт с общей лентой: всё, что пишут посетители, сразу видят все остальные — в реальном времени.

- **Сайт:** https://4rtem769.github.io/live-feed/
- Статический сайт: никакого сервера не нужно
- Realtime через публичный MQTT-брокер (WSS), данные не хранятся на каком-либо вашем сервере
- Летающие призраки показывают, кто сейчас на сайте

## Как это работает

- `index.html` + `styles.css` + `app.js` — весь сайт
- `vendor/mqtt.min.js` — MQTT-клиент (MQTT.js)
- Сообщения публикуются в топик `livefeed/v1/4rtem769/<комната>`
- Последние сообщения хранятся как retained-сообщения брокера — новый посетитель сразу видит историю
- Кто онлайн — retained-сообщения присутствия с MQTT-will

## Команды

- `/скример` (или `/screamer`) — случайному гостю из онлайна на весь экран вылетает скример.
  Выбирается случайный посетитель (по возможности не вы сами), перезарядка 10 секунд.
- `/дуэль` (или `/duel`) — вызов случайного гостя на дуэль кликов.
  Можно указать имя: `/дуэль Аня`. Соперник принимает вызов, затем 10 секунд на клики.
  Кто кликнул больше — получает +1 очко; очки видны в блоке «🏆 Очки» и хранятся в комнате.

## Магазин

Кнопка 🛒 в шапке. Очки из дуэлей тратятся на скины призрака и значки рядом с ником:

- **Скины:** Огненный (3), Ледяной (3), Токсичный (4), Королевский (6) — меняют цвет вашего призрака и аватара
- **Значки:** Огонёк (2), Череп (3), Корона (5) — видны рядом с именем в онлайне и в таблице очков
- Купленное сохраняется в браузере и публикуется в комнату (retained)

## Комнаты

По умолчанию комната `main` — все видят одну ленту.
Отдельная комната: добавьте `?room=название` к адресу, например:

```
https://<пользователь>.github.io/live-feed/?room=friends
```

## Важно

Сообщения идут через публичный брокер EMQX и доступны любому, кто знает адрес комнаты.
Не отправляйте туда пароли и личные данные.
